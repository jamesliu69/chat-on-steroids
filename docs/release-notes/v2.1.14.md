## 2.1.14: Selected upstream reliability fixes

This fork release carries selected upstream 2.1.14 improvements for queued input delivery,
attachment ownership, recovery, transcript continuity, browser ownership and worker/session
continuity. The app and companion are versioned as **2.1.14**; this selective integration keeps
Bridge Protocol **13**.

**Reload the companion extension and refresh your ChatGPT tabs after updating.** Refresh the CoS
connectors when prompted.
