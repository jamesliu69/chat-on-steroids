## 2.1.12

This release brings the fork up to the upstream 2.1.11 feature set while retaining its local extensions and reliability fixes.

- Goal/Loop decisions use authored conversation context without recorded tool bodies, with reasoning levels matched to the selected API model.
- Traditional Chinese remains the default UI and now covers the new setup guide, recovery countdowns, setup profiles and reasoning controls.
- Raspberry Pi/Linux ARM64 headless server support, tmux helpers, service installation and complete-quit behavior remain available.
- Setup-profile API keys now stay with the selected profile, failed key saves no longer block later profile changes, and plugin setup uses the active profile credential.
- Background command completion no longer causes forward history paging to skip intervening records.
- MCP attribution/identity hardening, lower-latency attribution and extension message validation are retained across the upstream integration.
- Windows release packaging includes both installer and portable executables, and CI now tests English copy explicitly without depending on the fork's Traditional Chinese default.

**Reload the companion extension and refresh the connectors in ChatGPT after updating.**
